## 一、国内稳健派（解决「买什么 / 怎么买」）

### 1. 林园 · 垄断价值派

- **一句话生平**：中国知名民间投资人，1989 年前后以数千元起步入市，长期重仓消费、医药等高确定性行业（如白酒、中药龙头），被称为「民间股神」。
- **核心心法**：
  - 只买「**嘴巴**」相关的生意——吃的、喝的、用的、治病的，老百姓每天离不开、需求最确定。
  - 找有**垄断性/定价权**的龙头，长期持有，伴随企业一起成长。
  - 不碰看不懂的复杂行业和高科技变量。
- **对普通家庭的启示**：与其追热点，不如盯住生活里天天要花钱、且换不掉的那几家公司。确定性 > 想象空间。
- **金句**：买股票就是买公司，买你每天都在消费、且离不开的公司。

### 2. 唐朝（唐书房）· 财报基本面派

- **一句话生平**：价值投资作者与博主，著有《手把手教你读财报》《价值投资实战手册》等，长期持有少数几家看得懂的优质公司。
- **核心心法**：
  - **远离杠杆**——绝不借钱炒股，这是反复强调的第一铁律。
  - 通过**阅读财报**理解一家公司怎么赚钱、赚的是不是真钱。
  - 在能力圈内，等优质公司被市场低估时买入，长期持有。
- **对普通家庭的启示**：看不懂财报没关系，但要守住「不借钱、只投闲钱、只买看得懂的」三条线。
- **金句**：理解生意 + 远离杠杆，比预测股价重要一百倍。

### 3. 银行螺丝钉 · 定投布道者

- **一句话生平**：指数基金投资科普作者，著有《指数基金投资指南》《定投十年财务自由》，以「螺丝钉估值表」帮普通人判断指数高估/低估而闻名。
- **核心心法**：
  - **宽基指数定投**——买一篮子优质公司，不用自己选股。
  - **低估值定投/越跌越买**——用纪律对抗人性的贪婪与恐惧。
  - 把理财当存钱罐，长期、自动、不间断。
- **对普通家庭的启示**：零基础起步的最佳路径——设一个每月固定金额、固定日期、自动扣款的宽基指数定投，设好就别频繁动。
- **金句**：好资产 + 好价格 + 长期定投，普通人也能跑赢大多数主动操作。

## 二、海外复利派（解决「耐心 / 全球视野」）

### 4. 罗纳德·里德 (Ronald Read) · 极简蓝筹派

- **一句话生平**：美国佛蒙特州人，一生做过加油站工人和百货公司清洁工，2014 年去世（享年 92 岁），留下约 800 万美元遗产，震惊全美。
- **核心心法**：
  - 只买**看得懂的超级大蓝筹**（消费、医疗、公用事业等），分散持有几十只。
  - **极度节俭**——把省下来的微薄收入持续投入。
  - **股息再投资**——拿到分红就继续买，让复利滚动几十年。
- **对普通家庭的启示**：收入高低不决定终局，「持续省 + 买大蓝筹 + 分红再投 + 活得够久」才决定终局。
- **金句**：财富不是赚来的高光，是几十年节俭与复利的沉淀。

### 5. 安妮·谢伯 (Anne Scheiber) · 稳健收息派

- **一句话生平**：美国国税局审计员，1944 年前后带着约 5,000 美元退休金开始投资，1995 年去世时滚成约 2,200 万美元，全部捐给大学。
- **核心心法**：
  - 寻找能**持续提高分红**的优质品牌企业，买入后**几乎从不卖出**。
  - 用她在税务局看懂的「哪些公司持续赚钱」的眼光选股。
  - **50 年定力**——把时间当作最大的武器。
- **对普通家庭的启示**：本金小不可怕，可怕的是没耐心。几千美元也能靠时间滚成上千万。
- **金句**：把时间拉到几十年，复利会做完你做不到的事。

### 6. 格蕾丝·格罗纳 (Grace Groner) · 无脑持有派

- **一句话生平**：美国雅培公司（Abbott）秘书，1935 年前后以约 180 美元买入 3 股雅培股票，之后股息全部再投资、一股未卖，2010 年去世时价值约 700 万美元，捐给母校。
- **核心心法**：
  - **穿越周期的死磕**——经历大萧条和无数次崩盘，一股没卖。
  - **忽略一切噪音**，几乎不操作。
  - **股息再投资**，让一笔小钱安静地滚 75 年。
- **对普通家庭的启示**：频繁交易是散户亏钱的最大根源；最高境界往往是「买了优质资产，然后忘记它」。
- **金句**：种下一棵树，别每天挖出来看根——浇水，然后让它自己长。

## 三、六人共识（圆桌的公约数）

无论国内海外、买股还是定投，六个人指向同一套底层常识：

1. **只投闲钱，远离杠杆**——绝不借钱、绝不梭哈。
2. **买看得懂的优质资产**——确定性 > 想象空间，看不懂的不碰。
3. **长期 + 复利 + 分红再投**——用「年」甚至「十年」做单位，时间是最大武器。
4. **纪律对抗人性**——少操作、不追涨杀跌，频繁交易是亏钱主因。
5. **节俭是源头**——能持续投入的闲钱，来自管住开支。

这五条，就是 skill 风险红线和工作流的来处。
