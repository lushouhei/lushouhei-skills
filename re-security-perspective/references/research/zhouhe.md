## 4. 方法论重点（核心：HOW he thinks）

> 这是本档案的重点。下面是从他的课程结构反推出的**思维镜片**与工作流。

### 工作流（推断，基于课程编排顺序）

1. **选一个"看得见结果"的活靶子**：用 KOF97 街机游戏作为逆向入门载体——目标具体、反馈直观（屏幕上能看到角色、碰撞、出招）。
2. **从指令集/调用约定打地基**：先吃透目标平台的汇编语义（M68000 / x64），再谈高层行为。
3. **机制逐个亲手复现**：把"图像显示""动态内存管理""指令输入""碰撞检测"当成独立实验，一个一个动手做通。
4. **逐级下沉到内核/硬件**：从用户态逆向 → 内核态机制（分页、提权、Hook）→ CPU 虚拟化扩展（VT-x/EPT）。层层下探"系统到底怎么运作"。
5. **同时研究"防护"与"绕过"**：课程同时讲 PatchGuard、DSE、SMEP/SMAP（防护机制）和 InlineHook、跨进程内存、提权（操作手法）——**攻防是一体两面**。

- **虚拟化/内核监控**：VT 课程涉及亲手配置 VMCS、处理 VM-Exit，意味着需要支持 Intel VT-x 的实验环境。

## 5. 核心心智模型

> 分层标注可信度。一手锚点 = 课程主题直接体现；推断 = 从编排逻辑外推。

### A. 高可信（有课程主题直接锚定）

1. **"先有摸得着的目标，再谈抽象原理"**（具象驱动学习）
   用一款真实游戏（KOF97）当逆向教具——抽象的汇编/内存只有挂在"屏幕上看得见的行为"上才学得动。锚点：KOF97 模块编排（先工具→汇编→具体游戏机制）。

2. **"逐层下沉，直到触到硬件"**（垂直深挖 mental model）
   思维方向是**往下钻**：应用 → 系统调用 → 内核分页/提权 → CPU 虚拟化扩展。不满足于"它能跑"，要问"CPU/内核这一层到底发生了什么"。锚点：x64汇编 → Windows内核实验 → VT 的递进。

3. **"攻防是同一枚硬币"**（防护机制 = 逆向地图）
   研究 PatchGuard/DSE/SMEP/SMAP 这些**防护**，本身就是为了理解如何在其约束下操作（Hook、提权、改内存）；反之亦然。看防护就是看"系统在防什么、所以弱点可能在哪"。锚点：内核研究模块同时含防护机制与操作手法。

4. **"每个机制都要亲手做一遍才算懂"**（实验主义 / 复现优先）
   命名为"内核实验"、24 讲逐机制拆解，体现"读懂≠会做，必须自己复现一遍"的认识论。锚点：模块命名与讲数密度。

### B. 基于有限信息推断（中可信，标注为推测）

5. **"虚拟化是最高观察位"**（推测）
   他把 VT-x/EPT 放在体系顶端，暗示一种镜片：**站在 hypervisor 这一层，你能在不被上层察觉的情况下观测/控制整个系统**——这正是"无痕 Hook""反外挂对抗"的思想根基。基于课程把 VT 作为进阶顶点的编排推断。

6. **"从游戏到内核，路径是连续的"**（推测）
   他的课程把"游戏逆向"和"内核/反外挂"放进同一体系，暗示其底层世界观：**所谓游戏外挂对抗，本质就是一场在内核/虚拟化层展开的逆向攻防**，技能是连续谱而非孤立科目。基于五模块同属一套课程体系推断。

### 决策启发式（他在"怎么学/怎么拆问题"上的口味，推断）

- 入门选**反馈直观**的靶子（游戏 > 抽象 demo）。
- 遇到"它怎么工作"先**下沉一层**找答案，而不是停在现象。
- 想绕过某机制，先把该**机制本身吃透**（研究 PatchGuard 才能谈对抗 PatchGuard）。
- 知识必须**落到可复现的实验**，否则不算掌握。
