# mao-shijianlun (实践论·知行闭环迭代器)

## R — 原文 (Reading)

> “判定认识或理论之是否真理，不是依主观上觉得如何而定，而是依客观上社会实践的结果如何而定。真理的标准只能是社会的实践... 认识从实践始，经过实践得到了理性认识，还须再回到实践去。马克思主义的哲学认为十分重要的问题，不在于懂得了客观世界的规律性，因而能够解释世界，而在于拿了这种对于客观规律性的认识去能动地改造世界。”
>
> — 毛泽东，《实践论》（一九三七年七月）

---

## I — 方法论骨架 (Interpretation)

任何可靠的系统认知与解决方案，必须通过“两次飞跃”与“四步提炼”构成闭环：
1. **第一次飞跃（实践到理性）**：深入一线场景直接感知客观现象（获取感性材料），但绝不停留在现象表面，必须通过“去粗取精、去伪存真、由此及彼、由表及里”的深度思考制作，提炼出系统的本质规律与理论假说。
2. **第二次飞跃（理性到实践）**：理论绝非用来束之高阁或单纯解释世界，必须转化为能动改造客观世界的行动方案，重新投放到实践中去接受严苛检验。
3. **螺旋上升循环**：一个正确的认知往往需要历经多次“实践-认识-再实践”的反复迭代与纠偏，直至主观预期与客观运行结果相契合。

## A1 — 书中的应用 (Past Application)

### 案例 1: 外来考察团赴延安的认知跃迁
- **问题**: 外界人士对延安和共产党的抗日主张存在大量偏见、怀疑与不信任。
- **方法论的使用**: 考察团前一两天仅看到街道、屋宇、接触各界人士、参加宴会（感性认识阶段）；随后考察团搜集各类文件与数据，经过开会讨论与深入分析（“想了一想”，理性认识阶段），由表及里地把握了抗日民族统一战线的本质。
- **结论**: 做出了“共产党的抗日民族统一战线政策是彻底的、诚恳的和真实的，且是能够成功的”科学判断。
- **结果**: 彻底扭转了局外人的刻板偏见，促成了海内外抗日力量的广泛政治互信与资源汇聚。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **架构/方案纸上谈兵**：团队在方案评审或设计阶段争吵不休，陷入理论与技术栈的形而上空谈，缺乏真实一线数据支撑。
2. **片面指标误导决策**：仅凭个别用户的抱怨或偶发日志报警就草率下结论，陷入盲人摸象式局部经验主义。
3. **系统复杂重构或排障**：面对未知的新型线上故障，既有代码规范与书本知识均已失效，需要从底层真实行为反推规律。

### 语言信号 (用户的话里出现这些就应激活)

- “这个架构理论上完美，但实际不知道行不行”
- “大家都在争执，各执一词怎么定夺”
- “我们是不是在纸上谈兵”
- “感觉是这个问题，但我拿不准”
- “怎么设计最小可行性验证来确认这个假设”
- “实践是检验真理的唯一标准 / 知行合一”

### 与相邻 skill 的区分

- 与 `mao-maodunlun` 的区别：`mao-maodunlun` 专注于**“全局战略资源分配与主要瓶颈定位”**（解决干什么、攻哪一点的问题）；而 `mao-shijianlun` 专注于**“方案如何从真实反馈中提炼与验证”**（解决知行如何闭环、真理如何验证的问题）。

## E — 可执行步骤 (Execution)

当本 Skill 被激活后，Agent 应严格按以下 4 步工作流推进：

1. **第一步：直接经验穿透（采集感性材料）**
   - 动作：拒绝仅看二手汇报或权威定论，直接调取一手真实生产环境数据（如原始访问日志、堆栈 Dump、真实用户脱敏行为流）。
   - 完成标准：掌握不少于 3 组具有典型代表性的第一手真实观测事实。

2. **第二步：四步加工制作（去粗取精、去伪存真、由此及彼、由表及里）**
   - 动作：
     - 去粗取精：过滤 90% 的心跳与心智噪音，提炼高信号变量；
     - 去伪存真：核验数据时间戳与上下文，排除伪故障与偶发伪相关；
     - 由此及彼：将孤立节点数据串联成链条；
     - 由表及里：输出本质因果假设（Hypothesis）。
   - 完成标准：形成一份明确的因果模型，解释现象背后的根本机制。

3. **第三步：能动改造闭环（设计检验行动）**
   - 动作：设计一个低成本的真实探针或最小灰度实验（A/B Test / 灰度切流 / 单点断言），将理性假设重新推回现实环境检验。
   - 完成标准：产出明确的“预期客观反应”对照表。

4. **第四步：差异修正与迭代循环**
   - 动作：对比实际执行结果与预想模型的差异：
     - 若完全符合：假设升级为确凿认知，纳入生产知识库；
     - 若出现偏差：立即触发“吃一堑长一智”，定位新发现的未知变量，返回第二步修正模型。
   - 判停条件：实际客观结果与预测指标偏差在允许阈值内。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯形式逻辑与数学运算**：如纯代数证明、哈希碰撞概率推导，此类问题属于形式符号系统，不依赖物质世界经验试错。
- **灾难性不可逆后果的高危场景且缺乏隔离层**：在缺乏沙箱环境的核心金融结算或核动力系统上，绝对不可用“盲目试错实践”来验证假设。

### 作者在书中警告的失败模式

- **生吞活剥的教条主义 (Dogmatism)**：以为死记硬背最佳实践或教条就能应付一切，拒绝根据客观现场调整认知。
- **狭隘封闭的经验主义 (Empiricism)**：认为只有自己亲眼见到的几行代码或局部个案才是真理，拒绝进行抽象思考与本质归纳。

### 作者的盲点 / 时代局限

- **规律可知论的绝对化**：时代背景受早期机械决定论与经典唯物主义影响，倾向于认为所有规律皆可在有限反复中被穷尽；在现代不可预测的复杂混沌系统（如混沌加密、自组织网络突变）中，认知需要承认系统固有的随机性与不可测性。

### 容易混淆的邻近方法论

- **敏捷开发与精益创业 (Lean Startup / Build-Measure-Learn)**：精益创业强调快速试错；`mao-shijianlun` 的独特性在于强调从感性到理性的**“四步严密逻辑制作”**，严禁未经深度思考的“低水平盲目轮转”。
