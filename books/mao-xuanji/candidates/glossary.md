# 候选关键术语词典 (Glossary Candidate Pool)

```yaml
- term: 实践 (Practice)
  source_chapter: 《实践论》
  source_quote: |
    "首先，马克思主义者认为人类的生产活动是最基本的实践活动，是决定其他一切活动的东西。人的认识，主要地是依赖于物质的生产活动... 辩证唯物论的认识论把实践提到第一的地位。"
  definition: |
    人类能动地探索和改造客观现实的物质性与社会性活动。是认识的唯一来源与检验真理的唯一客观尺度。在软件与 Agent 语境中对应于“在真实运行环境中执行动作、调用外部 API 并接收返回反馈”。

- term: 感性认识 (Perceptual Knowledge)
  source_chapter: 《实践论》
  source_quote: |
    "人在实践过程中，开始只是看到过程中各个事物的现象方面，看到各个事物的片面，看到各个事物之间的外部联系... 这叫做认识的感性阶段，就是感觉和印象的阶段。"
  definition: |
    事物外部表象和初步数据刺激在认知主体中的直接映射，包含现象、片面和外部联系。具有直接性但缺乏深度，尚未揭示内部因果与规律。

- term: 理性认识 (Rational Knowledge)
  source_chapter: 《实践论》
  source_quote: |
    "概念这种东西，已经不是事物的现象，不是事物的片面，不是它们的外部联系，而是抓住了事物的本质，事物的全体，事物的内部联系了。"
  definition: |
    对感性材料进行“去粗取精、去伪存真、由此及彼、由表及里”的抽象思维制作后，形成的概念、判断、推理与理论系统。反映事物的本质与系统规律。

- term: 主要矛盾 (Principal Contradiction)
  source_chapter: 《矛盾论》第四节
  source_quote: |
    "在复杂的事物的发展过程中，有许多的矛盾存在，其中必有一种是主要的矛盾，由于它的存在和发展规定或影响着其他矛盾的存在和发展。"
  definition: |
    在多矛盾交织的复杂系统中，起支配和决定地位、制约其他一切次要矛盾演进的核心瓶颈或杠杆点。

- term: 矛盾的主要方面 (Principal Aspect of a Contradiction)
  source_chapter: 《矛盾论》第四节
  source_quote: |
    "矛盾着的两方面中，必有一方面是主要的，他方面是次要的。其主要的方面，即所谓矛盾起主导作用的方面。事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的。"
  definition: |
    在同一对立矛盾体系中处于支配地位、决定事物当前状态与性质的一方（如防守方主导 vs 进攻方主导、劣势态 vs 优势态）。

- term: 矛盾的同一性 (Identity of Contradiction)
  source_chapter: 《矛盾论》第五节
  source_quote: |
    "第一，事物发展过程中的每一种矛盾的两个方面，各以和它对立着的方面为自己存在的前提，双方共处于一个统一体中；第二，矛盾着的双方，依据一定的条件，各向着其相反的方面转化。"
  definition: |
    对立双方互为依存前提、在一定临界条件下相互转化的动态属性。
```
