- id: f01
  title: 实践认知双重跃迁闭环 (实践-认识-再实践模型)
  type: framework
  source_chapter: 《实践论》
  source_quote: |
    "认识从实践始，经过实践得到了理性认识，还须再回到实践去。马克思主义的哲学认为十分重要的问题，不在于懂得了客观世界的规律性，因而能够解释世界，而在于拿了这种对于客观规律性的认识去能动地改造世界。"
  summary: |
    人类对复杂系统的有效认知必须经历两个不可分割的飞跃：
    第一跃迁（感性到理性）：从客观实践中收集原始数据与感知，经过逻辑重构提炼出本质概念和规律性假设；
    第二跃迁（理性到实践）：将提炼出的理论和方案重新投入现实行动中执行，以实践结果检验并修正初始假设。
    若无第一步则堕入盲目经验主义，若无第二步则沦为空头教条主义。
  tags: [decision, cognition, feedback-loop, execution]

- id: f02
  title: 感性材料四步制作法 (信息穿透式提炼框架)
  type: framework
  source_chapter: 《实践论》
  source_quote: |
    "要完全地反映整个的事物，反映事物的本质，反映事物的内部规律性，就必须经过思考作用，将丰富的感觉材料加以去粗取精、去伪存真、由此及彼、由表及里的改造制作工夫，造成概念和理论的系统，就必须从感性认识跃进到理性认识。"
  summary: |
    面对海量庞杂、真假参半的原始信息与日志时，执行四重过滤加工程序：
    1. 去粗取精：剔除冗余噪音，保留高信息密度的核心事实；
    2. 去伪存真：穿透表面宣传与幸存者偏差，核验数据真实性；
    3. 由此及彼：连接孤立数据点，寻找跨维度关联系数与网络结构；
    4. 由表及里：洞察表面现象背后的动力机制与系统结构本质。
  tags: [data-processing, analysis, cognitive-framework, information-refinement]

- id: f03
  title: 主要矛盾与支配地位诊断框架 (战略聚焦破局法)
  type: framework
  source_chapter: 《矛盾论》第四节
  source_quote: |
    "在复杂的事物的发展过程中，有许多的矛盾存在，其中必有一种是主要的矛盾，由于它的存在和发展规定或影响着其他矛盾的存在和发展。不能把过程中所有的矛盾平均看待，必须把它们区别为主要的和次要的两个方面，着重于抓主要矛盾。抓住了这个主要矛盾，一切问题就迎刃而解了。"
  summary: |
    多变量复杂困局下的破局法则：
    1. 穷举当前系统内存在的所有冲突与阻碍因素；
    2. 评估各因素之间的因果牵引关系，找出“若解决此问题，其他问题便能大幅缓解或自动解开”的支配性矛盾（主要矛盾）；
    3. 拒绝资源平均分配主义，集中 80% 以上兵力/算力打击该矛盾；
    4. 阶段性重新评估：主要矛盾解决后，原次要矛盾将上升为新主要矛盾，需切换战略重心。
  tags: [strategy, prioritization, bottleneck-analysis, resource-allocation]

- id: f04
  title: 矛盾主要方面与动态相变模型 (力量对比逆转法)
  type: framework
  source_chapter: 《矛盾论》第四节
  source_quote: |
    "矛盾着的两方面中，必有一方面是主要的，他方面是次要的。其主要的方面，即所谓矛盾起主导作用的方面。事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的。矛盾的主要方面和非主要方面在一定条件下互相转化。事物的性质也随着起变化。"
  summary: |
    分析某一具体矛盾系统当前状态与跃迁路径的动态模型：
    1. 识别矛盾双方力量消长（如攻守、强弱、亏盈）；
    2. 判断当前支配事物属性的主要方面（当前由何者主导）；
    3. 寻找并构筑“促成相变的核心外部/内部条件”；
    4. 持续强化自身力量累积，直至突破临界点（相变），使原本处于次要地位的力量跃升为主要支配方面。
  tags: [dynamics, phase-transition, leverage, power-dynamics]

- id: f05
  title: 矛盾特殊性与特异性匹配框架 (解法定制模型)
  type: framework
  source_chapter: 《矛盾论》第三节
  source_quote: |
    "不同质的矛盾，只有用不同质的方法才能解决。过程变化，解决矛盾的方法也须变化。用不同的方法去解决不同的矛盾，这是马克思列宁主义者必须严格地遵守的一个原则。"
  summary: |
    严禁一套架构/策略到处硬套的求解模型：
    1. 先界定问题的特殊质态（属于技术缺陷、组织信任、还是战略方向问题）；
    2. 匹配对应领域专属的解决范式，绝不可用解决 A 类问题的成功经验生搬到 B 类；
    3. 随问题发展阶段的变化，动态调整解题工具与手段。
  tags: [problem-solving, anti-dogmatism, adaptation]
