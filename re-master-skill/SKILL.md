# RE-Master-Skill: 逆向工程与网络安全大师体系

> 本技术手册为您聚合了安全界“海陆空”三大战区（PC恶意分析、硬件/漏洞挖掘、移动端及网络抓包）的顶尖心法。我们将不再停留在表层工具使用，而是直击计算机底层的“汇编、内存与通信网络”。

## 🧠 核心架构与专家方法论

### 1. 恶意软件追踪与降维分析 (PC / Malware)
*   **Marcus Hutchins (静态分析与沉淀池机制)**
    *   **战术核心**：拒绝完全依赖沙箱，直接剖析底层汇编与 Windows API 调用，追踪恶意软件的控制流图 (CFG)。
    *   **必杀技 (Sinkholing)**：通过逆向分析提取恶意软件的 C2 域名生成算法 (DGA)，抢注域名截获僵尸网络流量（如 WannaCry 阻断战役）。
*   **OALabs (动态调试与极致脱壳)**
    *   **战术核心**：构建基于 `FLARE-VM` 的纯净虚拟快照，使用 x64dbg 进行动态跟踪。
    *   **必杀技 (Unpacking)**：利用尾部跳转 (Tail Jump) 定位 OEP；面对强力反调试（如 Themida），通过监控 API，将调试器附加到被注入的“傀儡进程”上直接 Dump 内存。

### 2. 二进制漏洞与物理层攻击 (Exploitation & Hardware)
*   **LiveOverflow (内存破坏与漏洞构造)**
    *   **战术核心**：将程序视为存在缺陷的状态机。一切漏洞挖掘从可视化栈帧 (Stack Frame) 与寄存器变动开始。
    *   **必杀技 (ROP Chains)**：面对现代缓解机制 (ASLR/NX)，抛弃直接注入 Shellcode 的思路，转而寻找 Gadgets，在栈上拼凑 ROP 链以实现控制流劫持。
*   **stacksmashing (打破硬件黑盒)**
    *   **战术核心**：软件破不开，就用万用表和逻辑分析仪寻找 UART 和 JTAG 接口物理突破。
    *   **必杀技 (故障注入 Glitching)**：当面临物理熔断防线时，通过精确的电压/电磁干扰（侧信道攻击），迫使 CPU 在关键判断指令上跳过执行，实现固件提取。

### 3. 移动端对抗与流量解密 (Mobile & Network)
*   **r0ysue (Android 虚拟机构建与动态插桩)**
    *   **战术核心**：通盘掌握 ART 虚拟机机制。遇到混淆严重的加密不硬刚，直接使用 Frida RPC 建立通道，将 APP 作为黑盒进行“借鸡生蛋”式调用。
    *   **必杀技 (内存脱壳 FART)**：通过定制的系统底层主动触发方法调用，直接从内存中 Dump 修复被二代壳抽取的指令。
*   **周壑 (降维抓包与防线穿透)**
    *   **战术核心**：不局限于 Charles，必要时使用 Wireshark 进行网卡层分析，或 Hook 底层 Socket 接口进行“内存级明文抓包”。
    *   **必杀技 (双向 SSL Pinning Bypass)**：不仅在客户端 Hook 证书验证回调，更要从 APP 内提取解密密钥与 `.p12` 证书，导入抓包工具实现双向伪装。

## 🚀 学习路径与指令协议 (Learning & Execution Protocol)

为了使用本技能快速切入逆向工程，请遵循以下分层演练逻辑：

### Phase 1: 基础设施搭建
*   **行动**：使用 FLARE-VM 或自建快照部署 Windows 分析机；部署配有 Xposed/Frida 的 Android 测试真机或模拟器。
*   🔴 CHECKPOINT · 🛑 STOP: 请确认用户的分析机环境是否已完全隔离，并关闭了自动更新和网络共享功能，避免样本外泄。

### Phase 2: 降维打击练习
*   **网络篇**：随便找一个 APP 进行 HTTPS 抓包，如果遇到证书报错，调用 **周壑** 的知识库寻找 SSL Pinning 绕过方案。
*   **脱壳篇**：遇到被加固的样本，调用 **OALabs** 和 **r0ysue** 的思路，使用 x64dbg/FART 进行动态内存 Dump。
*   🔴 CHECKPOINT · 🛑 STOP: 确认用户手头的样本类型，选择最合适的工具栈（如 Xposed vs Frida，或是直接底层抓包）。

### Phase 3: 底层对抗与利用
*   使用 IDA Pro 静态逆向分析一段复杂的函数（遵循 **Marcus** 视角）。或者打一场简单的 CTF Pwn 题，尝试构造你的第一条 ROP 链（遵循 **LiveOverflow** 视角）。

## 异常处理与降级策略 (Fallback)

| 触发条件 | 一线修复动作 | 仍失败兜底方案 |
| :--- | :--- | :--- |
| 模拟器/测试机被检测到 Root | 启用 Magisk Hide 或 Shamiko 模块进行隐藏 | 换用无 Root 权限的备用真机进行黑盒测试 |
| 抓包工具抓不到 HTTPS 流量 | 检查系统证书是否正确安装到系统区，而非用户区 | 使用 Wireshark/tcpdump 从底层网卡直接抓包 |
| x64dbg 附加进程时直接闪退 | 检查反调试插件如 ScyllaHide 的配置是否开启 | 使用内核级调试器或硬件级快照恢复 |
