# 见路不走决策模型

## R — 原文 (Reading)

> “见路不走，即见理不走。不拘泥于过去的成功经验或现成的路子，而是根据当下的具体客观条件去决定如何行动。马克思主义的道理归根到底一句话：客观规律不以人的意志为转移。什么是客观规律？归根到底也是一句话：一切以时间、地点和条件为转移。”
>
> — 丁元英（豆豆），《遥远的救世主》 第34页

---

## I — 方法论骨架 (Interpretation)

“见路不走”是剥离经验主义的终极决策框架。人们在遇到问题时，习惯性地寻找“路”（别人成功的经验、过去管用的方法、书本上的教条）。但“路”是附着在特定时间、地点和条件上的，条件变了，“路”就成了死胡同。“见理”，就是要看透事物运转的底层因果逻辑（理）。不去管别人怎么走，也不去管自己以前怎么走，而是盘点当前手中的真实条件，条件具备什么，就做什么；条件不具备，就不做，或者去创造条件。

## A1 — 书中的应用 (Past Application)

### 案例 1: 创办格律诗音响公司
- **问题**: 王庙村的农民没有任何资金、技术和现代企业管理经验，如何在这个红海市场中创办一个能与行业巨头抗衡的公司？
- **方法论的使用**: 丁元英没有走常规的“招商引资、买设备建厂、打广告铺渠道”的“老路”（因为条件不具备），而是基于农民唯一的优势——不受劳动法限制的极端吃苦能力和极低成本（客观条件），将生产环节拆解为农户家庭作坊。
- **结论**: 不走正规军路线，走游击队+农户作坊的路线，这是唯一符合当时王庙村条件的“理”。
- **结果**: 建立起了巨头无法复制的成本优势，完成了降维打击。

1. 当用户试图照搬某位大佬或某家公司的成功经验，却发现水土不服时。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点客观条件 (Audit Conditions)**
   - 动作：引导用户列出当前手中的“真实筹码”（资金、资源、人力、时间、技术等）。
   - 完成标准：形成一份不带主观色彩的“可用资源清单”。

2. **剥离“路”（经验主义） (Remove Paths)**
   - 动作：让用户写出他们目前脑子里想走的老路、别人走过的路。然后逐一对比：别人的成功条件，你现在具备吗？过去的成功条件，现在还在吗？
   - 完成标准：用户认识到“照抄别人的路”或“走老路”在当前条件下是行不通的。
   - 判停条件: 如果用户当前的条件与过往完全一致，且条件充足，则可以直接走老路，结束 skill。

3. **推演“理”（底层因果逻辑） (Deduce Causality)**
   - 动作：抛开所有现成的做法，问自己：“要达到目标，最底层的必要条件是什么？”
   - 完成标准：找出达成目标的 1-3 个绝对必要条件。

4. **重构行动方案 (Reconstruct Action)**
   - 动作：基于步骤1的资源，去满足步骤3的必要条件。能满足，就干；不能满足，就想办法创造条件；创造不了，就放弃。这才是你该走的路。
   - 完成标准：输出一个专属于用户当前条件的、可能显得很“奇葩”但绝对合理的行动方案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯技术性问题**：比如“如何用 Python 写一个快排”，这种有绝对标准答案的技术问题不需要“见路不走”。
- **低风险、高确定性的日常事务**：比如办个证件、买个日用品，直接照前人的经验最快，强行“见路不走”是增加内耗。

### 作者在书中警告的失败模式

- **林雨峰的唯我独尊**：林雨峰因为过去太成功，陷入了“只有矛没有盾”的教条经验主义。当遇到不按套路出牌的丁元英时，他依然用大公司的老办法应对，结果一败涂地。他不肯“见理”，执着于过去的“路”。

### 作者的盲点 / 时代局限

- 丁元英的“不走寻常路”往往在道德和法律的边缘试探（如利用农民不受劳动法保护）。在当下社会，法律合规与 ESG 责任构成了绝对的“客观条件”限制。

### 容易混淆的邻近方法论

- **创新思维**：“见路不走”**不是**为了创新而创新，不是“非要走一条没人走过的路”。如果客观条件指向老路，走老路也是见路不走；如果指向新路，走新路也是见路不走。它唯理，不唯新旧。
